# terapadの設定ってなんなの？
フォルダの中に情報処理演習P1.tpcのアイテムがあるかと思います。
これにはエディタ上で表示される文字の色を指定する設定が含まれています。<br>最初の授業でterapadの設定をする際に色の変更をしなければならないですが、手作業で行うところでこれを使うと一発で授業で推奨される文字色へ設定されます。<br>必要に応じてお使いください。
> 1.ウインドウ上部の表示をクリック。<br>
> 2.メニュー内の「オプション」をクリック。<br>
> 3.色設定から「色情報読込」をクリック。

# Listと演習の違い。
ソースコードのタイトルにはそれぞれ大きく分けてListと演習の２つがあります。<br>それに当てはまらない物も一部ありますが、それはタイトルに書かれているものが書かれています。おそらく提出課題でしょう。
### List
Listは教科書に書かれている例文が書かれています。
> [!NOTE]
> タイトルで明示的に書かれていない限り、教科書通りのソースコードが書かれています。
### 演習
教科書に練習問題文が書かれています。***正解は一つとは限りません。***
